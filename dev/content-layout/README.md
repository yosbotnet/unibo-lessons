# Shared content layout

This pass addresses reading-column overflow without replacing scientific diagrams
with raster text, shrinking fonts, hiding columns or changing widget calculations.

`reader.css` and `reader.js` are the canonical sources. `sync.cjs` appends bounded,
identical generated blocks to the 22 existing course CSS/JS pairs. Existing course
differences outside those blocks are preserved. Keeping the original self-contained
bundles avoids introducing new network requests and offline PWA dependencies.

## Behavior

- Long standalone code/link strings and state labels can wrap. Native code listings
  remain horizontal scroll regions rather than being clipped by their surrounding
  annotated-code component. Fonts, palette and SVG geometry are unchanged.
- Course index metadata uses border-box sizing: its 100% mobile flex basis now
  includes indentation instead of extending beyond the viewport.
- Native tables outside figures gain a local scroll container. Rows, headers,
  captions and cell event listeners are moved intact, never recreated. Existing
  scroll owners and approved figure wrappers are not nested or modified.
- A region gets a visible hint, accessible name and keyboard focus only while it
  overflows. ResizeObserver and mutation observation cover tabs, new widget output
  and resizing. Removed tables are unobserved. There are no animation/polling timers.
- This enhancement requires JavaScript for new table wrappers; without JS, the
  original semantic table remains. Existing figure wrappers are source HTML and
  do not depend on this enhancement.

## Local repairs discovered during the pass

- ASMD 10: simulated draw tallies use pre-wrap instead of spilling long lines.
- IRS 13: load the existing lesson kit so the page receives the same table support.
- PM 10: cash-flow bars keep their widths and labels in a local scroll region.
- PM 13: six full descriptions are an ordered list beside concise selectors;
  option values and scoring are unchanged, and aria-describedby links the choices.
- DM 10.2 and its widget: the former plate contained **150 points despite claiming
  190**, with incorrect axis tick positions. The widget laid out 190 entries in
  rows unrelated to the parameter dimensions and displayed literal HTML entities.
  Both now use `dm/assets/search-space.js`: ten depths × nineteen tree counts,
  exactly 190 unique points. The same ten illustrative good configurations are
  highlighted, explicitly 10/190 ≈ 5.3%, not an empirical optimum or an exact 5%.
  The deck's separate probability example still assumes 5% (Modeling slides 39–40).
  The widget uses a real labeled table and roving keyboard selection; glyph size
  increased from .68rem to 14px. The SVG is generated by `dev/diagrams/search-space.cjs`.
- Reti LM 2–7 and ASMD 13: mathematical symbols assigned through textContent use
  Unicode rather than HTML entities. Numeric calculations are untouched.
- DL, Macro and Politics cache versions advanced. Macro's activation previously
  deleted caches belonging to other courses; cleanup now targets only `macro-*`.


The eight original reviewed script changes plus the Reti LM 5 symbol correction
are recorded with exact before/after hashes in `script-changes.json`. The broad
figure verifier continues rejecting every unreviewed script change; it no longer
mistakes empty external-script tags for inline widget code. Hashes record reviewed
versions, not correctness by themselves: browser interactions and mathematical
invariants provide the behavioral evidence.

## Evidence boundaries / remaining work

The HTML reflow audit visited all 315 tracked site pages at 1280 and 390 px:
178 initial overflow cases (2 desktop, 176 mobile), zero after repairs. It uses the
local highlight.js fixture and blocks other remote dependencies. It does **not**
certify legacy Mermaid figures: ten pages report missing Mermaid under this test
configuration. `ds/DS-C4.html` also has a preexisting null/style widget error, which
needs its own diagnosis. Both are recorded in the preview report, not suppressed.

The full objective still includes visual/scientific review of all graphs and
content, runtime graph rendering, browser interaction states beyond the tested
cases, and publication approval. The zero-overflow result is not completion of
that objective. Production remains untouched.
