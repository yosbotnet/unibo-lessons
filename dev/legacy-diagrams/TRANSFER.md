## Primary evidence and scope

- [Szegedy et al., Intriguing properties of neural networks](https://arxiv.org/abs/1312.6199): 2013 preprint, ICLR 2014; early transfer studies.
- [Goodfellow et al., Explaining and Harnessing Adversarial Examples](https://arxiv.org/abs/1412.6572): ICLR 2015; Figure 1 uses GoogLeNet, and 57.7% is the clean panda's class score, not a transfer rate.
- [Liu et al., v3](https://arxiv.org/pdf/1611.02770v3): ICLR 2017; §2.3 and Table 3. The sample is 100 ILSVRC-2012 images all five models classify correctly. Each row uses four source models and holds out the fifth. The new table copies only held-out top-1 target-label matching and mean RMSD: ResNet-152 38%/30.68; ResNet-101 43%/30.76; ResNet-50 46%/30.26; VGG-16 24%/31.13; GoogLeNet 11%/29.70. RMSD is in [0,255] pixel units, not L∞ epsilon. These are optimization-based targeted ensembles, not measured single-model FGSM rates. The geometric discussion does not equate boundary alignment with gradient alignment.
- [Kurakin et al., Adversarial Machine Learning at Scale](https://arxiv.org/abs/1611.01236): their experiments find multi-step attacks less transferable than single-step attacks; no universal reverse ranking is inferred.
- [Madry et al., Towards Deep Learning Models Resistant to Adversarial Attacks](https://arxiv.org/abs/1706.06083): projected optimization and first-order adversaries, not a global-optimum guarantee for any finite run.
- [Brown et al., Adversarial Patch](https://arxiv.org/abs/1712.09665): visibly added patches disprove imperceptibility as a universal requirement.

## Reproducible metrics and publishing pipeline

`cybersecurity/assets/transfer-evidence.cjs` is the shared downloadable source for
both chapters. It separates published records from five invented classification
records. The latter produce 2/4 targeted and 3/4 untargeted successes on eligible
inputs; conditioning on targeted source success yields 1/3 targeted transfer.
An excluded clean-error row and a source-failure/target-success row make the
denominator choice visible. Empty denominators are not represented as zero rates.

`transfer-test.cjs` checks all 486 single records and 236,196 pairs over three
classes against an independent counter, all 120 permutations of the illustration,
the targeted-implies-untargeted relation, empty input and seven invalid inputs.
It separately compares each selected literature cell to the downloaded PDF's
actual extracted Table 3 row, including the correct held-out column and RMSD.
No classifier, attack service or external model API is exercised by these tests.

`transfer-content.cjs` generates both section-6 bodies, illustration tables and
comparison/quiz corrections. Normal checks fail on content drift. Its patch mode
uses line-level diffs so unrelated chapter sections remain untouched. The shared
renderer still owns the marked figure blocks. Original-block hashes protect the
first diagram replacement; subsequent builds resolve its explicit markers.

```sh
NOTES_LIU_PDF=/path/to/1611.02770v3.pdf node dev/legacy-diagrams/transfer-test.cjs
node dev/legacy-diagrams/transfer-content.cjs --check
node dev/legacy-diagrams/build.cjs --check
node dev/legacy-diagrams/test.cjs
node dev/legacy-diagrams/font-test.cjs
node dev/legacy-diagrams/transfer-browser-test.cjs
```

Regenerate content by reviewing/applying `transfer-content.cjs` output, then
review/apply `build.cjs --patch`. Do not regenerate assets while browser regression
tests are loading them. Canonical source/data changes require rechecking the
original PDF and the independent metric tests, not just accepting a new snapshot.
