Primary evidence, read and checked:

  Definition 2.4, Proposition 2.1, group privacy and Theorem 3.16. The definition
  compares output events, not changes in the numeric value of an output. Adjacency
  and the protected unit must be declared. Post-processing needs no further
  access to the protected data; separate private accesses need accounting.

  The fine-tuning guarantee is not a retroactive guarantee for non-private

## Native figures and exact finite model

`cyber-dp-scope.svg` is generated by the shared Mermaid build adapter from five
named nodes/four arrows: protected data → DP training → released model → text;
fresh context → text is the separate vermilion input. For context held fixed
across neighboring training datasets, the original training guarantee can survive
even if this new context is copied. It does not imply protection of that context.

`cyber-dp-distributions.svg` is generated by `dp-plot.cjs` from the public
`cybersecurity/assets/dp-model.cjs`. This is a finite teaching calculation, not an
LLM, privacy accountant, production randomizer or empirical experiment.

- Neighboring inputs replace one bit x=0 with x=1. Return y=x with probability
  p (default .75), otherwise flip. The strict supported range is .5≤p≤.99.
- `text` emits NO/YES. `reuse` emits (y,y) from one draw. `fresh` emits two
  conditionally independent draws. `raw` emits (y,x), bypassing the mechanism.
- The complete common outcome domain is enumerated, including impossible outputs.
  Probability vectors are exact analytic expressions evaluated in double precision.
  Pure-DP bounds take the maximum ratio in both directions, treating positive/zero
  as infinity and ignoring zero/zero. Tests independently enumerate every event.
- At p=.75 the tight ε values are ln(3), ln(3), 2ln(3) and infinity. In the last
  case, the event “last bit is zero” has probabilities 1 and 0, ruling out any
  finite ε with δ<1. Approximate-DP accounting is not otherwise implemented.
- Plot colors identify neighboring input distributions, not attack success.
  All mini-axes use probability 0–1, bars derive from the model, and numeric labels
  round to four decimals. The complete data is downloadable. Bounds are displayed
  in an HTML table rather than tiny annotations in the SVG.

Both figures keep ivory/cobalt/vermilion, the embedded original IBM Plex Mono at
14px and straight/angular connections. The plot was widened to 820×565 after
visual inspection found nearly touching probability labels; font size was not
reduced. The scope diagram is 509×336. Mobile uses native-size keyboard-scrollable
regions with no hidden overflow or shrunken text.
